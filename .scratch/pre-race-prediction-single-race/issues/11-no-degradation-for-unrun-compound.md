## Comments

**From ticket 08 (2026-10-20).** Of 7 recent conventional 2024 races screened, 3 are refused for this reason: Monza, Abu Dhabi and Las Vegas, all on the Hard. At Monza only Tsunoda ran Hards (three FP1 Stints: one Push Lap per set, or a 3-lap run below the 4-lap Long Run minimum), and the five FP3 Hard laps are all in-laps. Yet all 20 starters raced the Hard.

Options to weigh, all modelling decisions that likely need an ADR because they reverse ticket 02:
- Borrow the next-softer Compound's field-average Degradation as an upper bound (harder Compounds rarely wear faster), with a new Degradation source.
- Use the circuit's Degradation from previous seasons' races (needs a history store; fits with Circuit Tendency).
- Fit from shorter runs only for Compounds that would otherwise have nothing (lower `min_long_run_length` per Compound).

**Triage (2026-10-20).**

> *This was generated by AI during triage.*

**Decision:** when no team has Long Runs or Push Laps on a dry Compound, estimate its Degradation from previous seasons' race Stints at the circuit. If there is no usable history either, use the next-softer Compound's field-average Degradation as an upper bound (a harder Compound is assumed to wear no faster). Reason: race Stints are real race running on that Compound, better data than any short practice run, and the loader already reads previous seasons' races at the circuit for Pit Loss; this history also feeds Circuit Tendency next. This reverses ticket 02's "never invent a rate" refusal, so it gets an ADR. Rejected: fitting shorter practice runs for that Compound only (noisier, and Monza 2024 still has almost nothing).

## Agent Brief

**Category:** enhancement
**Summary:** Predict races where nobody ran a dry Compound in practice, using circuit race history, then a next-softer bound.

**Current behavior:**
The Degradation model raises "No Long Runs or Push Laps on <Compound> across the field" and the prediction fails. Monza, Abu Dhabi and Las Vegas 2024 can't be predicted (all on the Hard).

**Desired behavior:**
The Degradation fallback chain gains two steps after the field average: (1) a field-level Degradation for the Compound fitted from previous seasons' race Stints at the same circuit (current regulations, 2022+, recent seasons counting more, never the race being predicted), fuel-corrected the same way as practice; (2) if that history is missing, the next-softer Compound's field-average rate. Each estimate's source says which step produced it. The command reports the source in its header, so a run that leaned on history or the bound is visible. If even the bound is unavailable (e.g. nobody ran any dry Compound), prediction is refused with a clear message from the command, not a traceback.

**Key interfaces:**
- `DegradationSource`: two new members, for circuit race history and for the next-softer bound
- `PreRaceInfo`: carries the circuit's historical race Degradation per dry Compound (or whatever the loader needs to compute it), built only from previous seasons
- The FastF1 weekend loader: reads previous seasons' race Stints at the circuit, reusing the past-race loading it already does for Pit Loss
- `predict()`: no longer raises for a Compound with no practice running when a later fallback step applies

**Acceptance criteria:**
- [ ] A hand-built weekend where nobody ran the Hard, with circuit race history, predicts using a history-sourced Hard rate
- [ ] The same weekend without history uses the next-softer bound, with that source reported
- [ ] Neither fallback is used when any team ran the Compound
- [ ] Historical Degradation never uses the race being predicted (a no-leakage test)
- [ ] Monza 2024 can be predicted by the command
- [ ] A weekend where no fallback applies gives a clear refusal message from the command, exit code 2
- [ ] ADR-0003 (written at triage) still matches what was built; update it if the implementation differed
- [ ] `CONTEXT.md` gains a term for circuit race-history Degradation if the work needs one

**Out of scope:**
- Circuit Tendency (strategy frequencies), which is a separate spec
- Using history to adjust Compounds that teams did run in practice
- Per-team historical Degradation
