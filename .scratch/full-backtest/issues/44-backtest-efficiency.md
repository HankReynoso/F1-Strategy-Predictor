# 44: Backtest efficiency: avoid repeated loading and computation

**What to build:** Make a full Backtest do each piece of work once. The code review found: each 2022 race is parsed from the cache up to 4 times per Backtest, and OpenF1 history similarly; practice sessions are classified twice per race; Stop Windows are computed with a slow nested loop and recomputed for teammates with identical rates; and the OpenF1 race loader fetches race laps and pit data it never uses (about 48 wasted requests per season).

- [ ] Practice classification runs once per race
